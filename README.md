# R_pamokos_LT
Lietuviškų R pamokų kodai ir duomenys / Code and data for Lithuanian R tutorials.

Čia pateikta R statistikos pagrindų pamokų medžiaga lietuvių kalba. 

Visas pamokas su išsamiais paaiškinimais galite rasti **YouTube kanale [@BioMatika_lt](https://www.youtube.com/@BioMatika_lt)**.

---

## Turinys

Šioje saugykloje esantys aplankai skirti atskiriems YouTube pamokų įrašams:

1. **`1_R_ivadas`** – Įvadas, duomenų įkėlimas, aprašomoji statistika ir duomenų normalumas.
2. **`2_R_grafinis_vizualizavimas`** – Grafinio vizualizavimo pagrindai (base R ir ggplot2).
3. **`3_R_koreliacine_analize`** – Koreliacinė analizė ir koreliacijų matrica, Spearman ir Pearson koreliacijos koeficientai.
4. **`4_R_t_testas_ir_wilcoxon_testas`** – T-testas ir Wilcoxon testas.
6. **`5_R_ANOVA_ir_Kruskal-Wallis`** – ANOVA, Kruskal-Wallis bei post hoc testai (Tukey's HSD ir Dunn's).
7. **`6_R_2_veiksniu_ANOVA`** – Dviejų veiksnių (two-way) ANOVA su dėžučių ir linijine diagramomis.
8. **`7_R_chi_kvadrato_testas`** – Chi kvadrato testas (Chi-Squared Test).
9. **`8_R_lenteliu_eksportavimas`** – Statistinių rezultatų bei lentelių eksportavimas į MS Excel ir Word.

## Kaip naudotis šia medžiaga?

1. **Atsisiųskite arba klonuokite saugyklą:**
   ```bash
   git clone [https://github.com/gabija-vaitkev/R_pamokos_LT.git](https://github.com/gabija-vaitkev/R_pamokos_LT.git)
   ```
2. **Su RStudio atsidarykite atitinkamos pamokos kodo failus (.R).**

3. **Kode pateikti paaiškinimai, bet galite užduotis atlikti kartu žiūrėdami atitinkamą pamoką mūsų YouTube kanale [@BioMatika_lt](https://www.youtube.com/@BioMatika_lt).**
